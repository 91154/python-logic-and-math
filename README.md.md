# Python Logic Exercises

This repository contains various coding challenges solved using different programming paradigms.

## 📂 Projects

### 1. Digit Counter
A program to count how many times a specific digit appears in a number. I have implemented this in three different ways to show different approaches:

| File Name | Approach | Logic Description |
| :--- | :--- | :--- |
| `math_approach.py` | **Mathematical** | Uses `while` loop, modulo (`%`), and floor division (`//`). |
| `string_approach.py` | **Pythonic** | Converts the number to a string and uses the `.count()` method. |
| `input_as_string.py` | **Direct String** | Takes input directly as strings to simplify the process. |
